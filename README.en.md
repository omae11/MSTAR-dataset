# MSTAR SAR Target Recognition Dataset

🌐 **Languages / 语言**: [English](./README.en.md) · [中文](./README.md)

A mirror of the **MSTAR (Moving and Stationary Target Acquisition and Recognition)** public-release dataset for SAR (Synthetic Aperture Radar) automatic target recognition (ATR) research. This repository bundles the two most widely used subsets:

| Subset | Format | Size | Description |
|--------|--------|------|-------------|
| [`soc/`](./soc)         | Intensity (`.jpg`)  | ~11 MB  | Real-valued **intensity / magnitude images** (158×158, 8-bit grayscale) generated by detecting the `soc_complex/` raw data — ready to feed into standard CV models |
| [`soc_complex/`](./soc_complex) | Complex (extension varies by class, see below) | ~923 MB | SOC raw complex SAR data (magnitude + phase blocks); detect it yourself to obtain magnitude / intensity / phase images |

> The two subsets share **identical filenames and folder structure**, so you can switch between intensity-image and complex inputs by simply pointing your dataloader at the other folder.

---

## Background

MSTAR was collected by the **Air Force Research Laboratory (AFRL)** and the **Defense Advanced Research Projects Agency (DARPA)** in the 1990s. It contains X-band SAR imagery of military ground vehicles measured at varying depression angles. The Standard Operating Conditions (SOC) split — **17° depression for training, 15° for testing** — has become the canonical benchmark for SAR ATR.

Each chip is a 128×128 (or 158×158, with padding) SAR image centered on a ground target.

## Filename Convention

`soc_complex/` uses `train/` (17° depression) / `test/` (15° depression) folders to separate the splits.
**The file extension varies by target class** (observed: 2S1→`.000`, BMP2→`.000`, BRDM2→`.001`, T72→`.015`, ZSU234→`.026`, etc.) —
do not use the extension to tell train/test apart.

Examples:
- `soc_complex/train/2S1/HB14931.000` — 2S1 training chip
- `soc_complex/test/T72/HB03335.015` — T72 test chip

The `soc/` intensity images share the same base names with `.jpg` extension (158×158, 8-bit grayscale).

## Usage

### Python — quick loader for intensity images
```python
from torchvision import datasets, transforms

dataset = datasets.ImageFolder(
    root='soc/train',
    transform=transforms.Compose([
        transforms.Grayscale(),
        transforms.Resize((128, 128)),
        transforms.ToTensor(),
    ])
)
print(f'{len(dataset)} training samples, {len(dataset.classes)} classes')
```

### Python — loader for complex SAR data
```python
import re
import numpy as np

def load_complex_chip(path):
    """Read one complex chip; returns the complex image (size taken from the header).

    File layout (Phoenix format, verified):
      Phoenix ASCII text header (length given by PhoenixHeaderLength inside the
      header itself; observed 1594/1973/1976 bytes — do not hard-code it)
      + NumberOfColumns x NumberOfRows big-endian float32 magnitude block
      + NumberOfColumns x NumberOfRows big-endian float32 phase block (radians)
    Complex image = magnitude * exp(1j * phase).
    Note: NOT interleaved real/imaginary, and there is no fixed 128x128 size.
    """
    with open(path, 'rb') as f:
        raw = f.read()
    head = raw[:4096].decode('ascii', errors='replace')

    def field(key):
        m = re.search(r'^' + key + r'\s*=\s*([0-9]+)', head, re.M)
        return int(m.group(1))

    hlen = field('PhoenixHeaderLength')
    ncol = field('NumberOfColumns')
    nrow = field('NumberOfRows')
    data = np.frombuffer(raw[hlen:], dtype='>f4')
    n = nrow * ncol
    mag = data[:n].reshape(nrow, ncol)
    pha = data[n:2 * n].reshape(nrow, ncol)
    return mag * np.exp(1j * pha)
```
